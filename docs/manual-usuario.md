# Manual básico de usuario

## Abrir la demostración

Abra `demo/index.html` con un navegador moderno. No requiere instalación.

## Editar una cohorte

1. Ingrese a **Presupuestos**.
2. Modifique año, semestre, duración y estudiantes.
3. Ajuste overhead de facultad, reconocimiento de matrícula y arrastre.
4. Registre estudiantes y horas por semestre.
5. Revise las advertencias de consistencia.
6. Consulte el resumen y el flujo de caja anual.
7. Presione **Guardar borrador** para conservar los datos en el navegador.

## Consolidado

La vista **Consolidado** integra dos cohortes de demostración y muestra cuánto gasto duplicado se evita al normalizar dirección, asistencia, gastos operacionales y software.

## Restaurar datos

En el editor, presione **Restaurar** para volver al caso de demostración inicial.
