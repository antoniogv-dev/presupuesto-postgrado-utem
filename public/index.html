Reglas generales

Los descuentos y las becas internas se descuentan primero del arancel bruto. Sobre ese arancel se aplica la incobrabilidad. El resultado es el ingreso neto por arancel. El overhead central y el overhead de facultad se calculan sobre ese ingreso neto. La matrícula se mantiene separada y sólo se incorpora según el porcentaje definido para cada presupuesto.
